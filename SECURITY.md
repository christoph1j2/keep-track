# Security Policy

## Supported Versions

Keep Track is currently in active development (Beta). Only the latest beta release is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| Latest / `v1.0-beta.x` | :white_check_mark: |
| Older forks | :x:                |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability within Keep Track, please send an e-mail to Ernst Christoph Leschka at ernst.leschka@gmail.com. 

I will try to respond to the report as quickly as possible and keep you updated on the progress of the patch.
